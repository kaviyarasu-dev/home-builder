⚠ Known risk: ✨ Enhance can change things the checker does not guard

What is checked. After Enhance, the program only confirms that the “locked” lines still appear word-for-word (location, plot, plot extent, floors, one line per floor, setbacks + envelope, parking: 9 lines with the default 2 floors) and that the length is 300–30,000 characters. It also confirms that every ticked deliverable name and PART marker is still present. If those pass, the rewrite is accepted.

What is NOT checked (Claude may reword, weaken or drop these, and the prompt is still accepted): budget and finish level, special requests, slope, coverage / FSI, new-or-old work and use, family / mobility, levels (plinth, floor height), stair details, outdoor / terrace / services, style, roof, wall / door / column / room-minimum values, blocked boundary sides, shafts, Vastu, and the mandatory rules themselves (STAIR LOCK, stack lock, no questions, number of designs, “nothing verified unless the script printed it”). The meta-prompt asks Claude to keep them, but no code enforces it.

Stale result. If you edit the form or run Auto-fill while Enhance is still running, the old request is not cancelled. Its reply is checked against the old answers and then shown, so the enhanced prompt can reflect values you have already changed.

“Changes” list. It is Claude's own summary of its edit, not a diff, so it can be incomplete.

What to do. Treat Enhanced text as a draft: compare it with the original (↩ Restore original) before copying, and re-check any parameter you care about that is not in the locked list above.
